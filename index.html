Codex Usage Monitor — Privacy Policy

Last updated: September 27, 2026

Summary: Codex Usage Monitor processes the user's ChatGPT Usage information locally in the browser. It does not send usage data to the developer or to an external backend, and it does not use telemetry, analytics, advertising, or tracking.

1. What the extension reads

Codex Usage Monitor reads only the information needed from the user's ChatGPT Usage page to provide its monitoring features. This may include the displayed 5-hour and Weekly usage limits, remaining percentages, and reset timing information when available.

The extension does not read ChatGPT conversations, personal messages, passwords, authentication tokens, payment information, or location data.

2. How the information is used

The information read from the ChatGPT Usage page is used only to:

  • display the user's current Codex usage status;
  • perform automatic or manual usage checks;
  • show local quota-threshold or replenishment notifications; and
  • maintain the extension's local operational state.

3. Local storage

The extension stores its settings and limited operational state in browser extension storage. This may include the selected check interval, pause/resume state, last validated usage status, and alert state needed to avoid duplicate notifications.

This locally stored information is not transmitted to the developer or to an external backend.

4. Data transmission and sharing

Codex Usage Monitor has no developer-operated backend and does not transmit usage data to the developer. It does not sell, transfer, or share user data with third parties for advertising, analytics, profiling, creditworthiness, lending, or unrelated purposes.

When the extension opens or reloads the normal ChatGPT Usage page, the user's browser communicates with ChatGPT/OpenAI as part of loading that website. This is normal website traffic between the user and ChatGPT/OpenAI and is not data sent to the developer of Codex Usage Monitor.

5. Notifications

If enabled by the user and permitted by the browser or operating system, the extension may display local notifications containing usage-related information. These notifications are generated on the user's device.

6. Retention and deletion

Extension settings and operational state remain in the browser's extension storage until they are cleared or the extension is removed. Codex Usage Monitor does not maintain a separate server-side copy of this information.

7. Changes to this policy

This policy may be updated if the extension's behavior or data practices change. The “Last updated” date at the top of this page will be revised when material changes are made.

8. Contact

For questions about this privacy policy or the extension's privacy practices, please use the support channel provided on the Codex Usage Monitor Chrome Web Store listing.

Codex Usage Monitor is an independent browser extension and is not affiliated with or endorsed by OpenAI.
